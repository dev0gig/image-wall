Visual Archive Guide

Supported Sources

Currently, this tool supports X (Twitter) accounts. You can simply type the handle (e.g. ArchDigest), use an @ prefix (e.g. @ArchDigest), or paste the full X profile URL.

Limits

To ensure performance and respect API boundaries, the tool fetches a maximum of 20 latest images per channel/account.

Favorites & Downloads

Click the heart icon on any image to save it to your Favorites. In the Favorites view, you can download all your curated images as a single ZIP archive.

Import & Export

Use the Backup options to export your saved channel list to a JSON file. You can import this file later or on another device to restore your channel collection. Note: This only backs up the channel handles, not the images themselves.
